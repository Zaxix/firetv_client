# Dolby Vision RPU fixtures for CI

`profile5.rpu` and `profile7-fel.rpu` are single-frame Dolby Vision RPUs copied from the test
assets of [dovi_tool](https://github.com/quietvoid/dovi_tool) (`assets/tests/profile5.bin`,
`assets/tests/fel_orig.bin`), MIT License, Copyright (c) quietvoid. `ci/make_samples.sh` repeats
them once per frame and injects them into a generated HEVC stream with `dovi_tool inject-rpu`, so
the CI Jellyfin server sees profile 5 and profile 7 files. Profile 8.1 RPUs are generated by
`dovi_tool generate`. The picture content of these samples is the synthetic test pattern; only the
Dolby Vision signalling matters for the tests.
